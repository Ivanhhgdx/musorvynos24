# МусорВынос24

Демонстрационный сайт будущего сервиса пешего выноса бытовых пакетов в Красноярске.

[Открыть сайт](https://ivanhhgdx.github.io/musorvynos24/)

## Возможности

- Лендинг, разовый тариф и подписка, правила передачи пакетов, планируемая зона, FAQ, будущие курьеры и поддержка.
- Интерактивное оформление: 1–4 пакета, 35/60 л, дата, интервал, подписка 4/8/12 визитов, расчёт и подтверждение.
- Оплата и вызов курьера не подключены. Данные остаются в форме браузера и никуда не отправляются.
- Цены, интервалы и условия демонстрационные. Конкретный ЖК и дата пилота не определены.

## Файлы

`index.html` — самодостаточный интерфейс; `courier.png` — оригинальное сгенерированное изображение с прозрачностью; `launch-guide.html` и `launch-guide.md` — исследование запуска с источниками, проверенными 04.10.2026.

## Локальный запуск

```sh
python3 -m http.server 4196 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4196/ . Сборка и установка зависимостей не требуются. Публикация: GitHub Pages из корня ветки main.

Изображение курьера создано с помощью OpenAI image_gen специально для проекта и не представляет действующего сотрудника.
